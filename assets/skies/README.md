# Photographic 360° skies

The eight equirectangular sky panoramas in this folder are resized, tonemapped
JPG derivatives of Poly Haven HDRIs. Poly Haven assets are released under the
CC0 license: https://polyhaven.com/license

| Local file | Poly Haven source |
| --- | --- |
| `clear.jpg` | [Kloofendal 43d Clear (Pure Sky)](https://polyhaven.com/a/kloofendal_43d_clear_puresky) |
| `scattered.jpg` | [Kloofendal 48d Partly Cloudy (Pure Sky)](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) |
| `cirrus.jpg` | [Autumn Field (Pure Sky)](https://polyhaven.com/a/autumn_field_puresky) |
| `overcast.jpg` | [Overcast Soil (Pure Sky)](https://polyhaven.com/a/overcast_soil_puresky) |
| `shower.jpg` | [Wasteland Clouds (Pure Sky)](https://polyhaven.com/a/wasteland_clouds_puresky) |
| `snow.jpg` | [Snow Field (Pure Sky)](https://polyhaven.com/a/snow_field_puresky) |
| `golden.jpg` | [Qwantani Sunset (Pure Sky)](https://polyhaven.com/a/qwantani_sunset_puresky) |
| `night.jpg` | [Qwantani Moon Noon (Pure Sky)](https://polyhaven.com/a/qwantani_moon_noon_puresky) |

The panoramas provide the visible sky only. NAPKIN's sun geometry, shadows,
wet-ground response, rain and snow remain live model effects.
